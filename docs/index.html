Pure PHP · Hrana over HTTP · No native extension

libSQL for PHP,
over plain HTTP.

Turso Client HTTP is a pure-PHP client for libSQL and Turso Cloud. It speaks Hrana over HTTP, runs anywhere ext-curl works, and gives you a familiar query builder, schema builder, transactions, and Laravel integration — without compiling a native extension.

Get started View on GitHub
$ composer require darkterminal/turso-client-http

MIT licensed · PHP 8.3+ · ext-curl/ext-json/ext-mbstring · latest release on GitHub

quick-start.php 
use Darkterminal\TursoHttp\LibSQL;

$db = new LibSQL(
    "libsql://your-db-org.turso.io",
    ["authToken" => $token]
);

$users = $db->query(
    "SELECT name FROM users WHERE active = ?",
    [1]
)->fetchArray(LibSQL::LIBSQL_ASSOC);

One DSN, one client. Query Turso Cloud or a self-hosted sqld over HTTP.

Why this client

Portable libSQL access,
without native setup.

The same libSQL workflow, delivered as a pure-PHP package you can install with Composer.

Pure PHP, Hrana over HTTP

No compiled extension, no FFI. If PHP can make HTTP requests, it can talk to libSQL.

Familiar PHP API

query(), execute(), prepare(), transaction(), and fetch modes that feel at home in PHP.

Turso Cloud & sqld

Point the same client at Turso Cloud or a self-hosted libsql-server. Local dev, CI, and production share the same code path.

Builder included

Fluent query builder and schema builder for common CRUD and table operations, backed by the same HTTP pipeline.

Transactions

Interactive transactions with commit() and rollback(), or batch execution for simple scripts.

Laravel ready

Auto-discovered service provider and facade. Configure TURSO_DATABASE_URL/TURSO_AUTH_TOKEN and inject the client.

Quick start

Up and running in minutes.

Install the package, point it at a libSQL endpoint, and query.

1

Install

Composer pulls the package. No extension compile, no php.ini change.

terminal
composer require darkterminal/turso-client-http
2

Connect

Use a Turso Cloud URL or a local/self-hosted sqld endpoint.

connect.php
use Darkterminal\TursoHttp\LibSQL;

$db = new LibSQL(
    "libsql://db-org.turso.io",
    ["authToken" => getenv('TURSO_AUTH_TOKEN')]
);
3

Query

Use raw SQL, prepared statements, builders, or transactions — same client.

query.php
$db->executeBatch("
  CREATE TABLE IF NOT EXISTS users (id INTEGER PRIMARY KEY, name TEXT);
  INSERT INTO users (name) VALUES ('Ada');
");

$rows = $db->query("SELECT * FROM users")
    ->fetchArray(LibSQL::LIBSQL_ASSOC);
